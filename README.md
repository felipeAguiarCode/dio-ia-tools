# DIO IA Tools

> **EXPLORE · BUILD · CREATE** — suas ferramentas favoritas de inteligência artificial em um só lugar.

🔗 **Acesse:** https://felipeaguiarcode.github.io/dio-ia-tools/

Hub em formato "link na bio" que reúne as ferramentas de IA da DIO, com um story estilo Instagram exibindo um cupom de desconto.

## Ferramentas

| Ferramenta | Categoria | Descrição |
| --- | --- | --- |
| [DIO Explorer](https://felipeaguiarcode.github.io/dio-explorer/) | Roadmap & aprendizado | Descubra trilhas e monte seu plano de estudos. |
| [Skill Hub](https://felipeaguiarcode.github.io/skillhub/) | Skills & comunidade | Explore um catálogo de skills e crie as suas. |
| [Agent Studio](https://felipeaguiarcode.github.io/my-agent-studio/) | Agentes de IA | Crie e configure seus próprios agentes de IA. |
| [Dashboard Studio](https://felipeaguiarcode.github.io/dashboard-studio/) | Dashboards & design | Desenhe painéis e gere especificações de UI. |

## Destaques

- **Story com cupom** — clique no avatar para abrir o story com o cupom `DIOIA75` (75% OFF nos planos DIO), botão de copiar, contagem regressiva e gesto de arrastar para cima.
- **Fundo aurora** animado em degradê e animações de entrada.
- **Página única** — HTML, CSS e JavaScript puros em um só arquivo, sem dependências nem build.

## Rodando localmente

Basta abrir o `index.html` no navegador, ou servir a pasta:

```bash
npx serve .
```

## Deploy

Publicado via **GitHub Pages** a partir da branch `main` (raiz `/`). Cada push na `main` atualiza o site automaticamente.
